Weapon License Application
PF执照《武器购买许可证》 Firearm Purchase License · 请仔细阅读以下须知

办理须知

  1. 《圣安地列斯州热武器管理法》
  2. 每位市民只能同时拥有3支合法武器；
  3. 市民拥有的合法武器禁止加装一切配件；
  4. 只拥有PF执照的市民只能将合法武器存放在自己名下的房产与自己名下的车辆内，不允许携带在身上。

申领条件

  1. 美国圣安地列斯州公民。
  2. 必须有一栋房屋或者一辆汽车用于存放枪支。
  3. 年满 22 周岁。
  4. 圣安地列斯州境内无任何犯罪记录，包括轻罪拘役记录。
---申请--- 请根据下面的格式，在「PF执照申请」频道内提交PF执照办理申请； 我们会核实你的信息，审核通过后会有人员联系您进行办理； 通过后请携带ID卡，以及现金前往办理。
---办理--- 当你被通知前往办理，请在规定时间前往警局面试、办理； 你会被要求出示身份证件，请确保以上物品随身携带； 你会被要求回答数个问题，以确保你已知晓相关法律事项； 如果你的回答不尽人意，你的申请将会被否决； 面试可能在某些不可抗力的因素影响下被拒绝或中断。
---费用--- 每次面试将会花费5000美金，不论通过与否，费用不退还； 证件办理将会花费5000美金，每次办理请准备至少10,000美金。
CCW执照《隐蔽携带枪支许可证》 Concealed Carry Weapon · 请仔细阅读以下须知

办理须知

  1. 《圣安地列斯州热武器管理法》
  2. CCW执照只允许持证人在其房产、产业、私人领地与车辆内部携带火器；
  3. CCW执照只允许持证人行使自卫权、堡垒法与公民逮捕权；
  4. CCW执照只允许持证人用衣物将火器隐藏起来携带，不得佩戴外置枪套。

申领条件

  1. 持有合法的PF执照。
  2. 洛圣都公职单位、执法机构、安保公司雇员。
---申请--- 请先根据下面的格式，在对应的「CCW申请频道」内提交CCW执照办理申请； 我们会核实你的信息，审核通过后会有人员联系您进行办理； 通过后请携带ID卡，以及现金前往办理。
---办理--- 当你被通知前往办理，请在规定时间前往警局面试、办理； 你会被要求出示身份证件，请确保以上物品随身携带； 你会被要求回答数个问题，以确保你已知晓相关法律事项； 如果你的回答不尽人意，你的申请将会被否决； 面试可能在某些不可抗力的因素影响下被拒绝或中断。
---费用--- 每次面试将会花费5000美金，不论通过与否，费用不退还； 证件办理将会花费5000美金，每次办理请准备至少10,000美金。
